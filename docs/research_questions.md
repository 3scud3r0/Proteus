# Research roadmap

1. Does experience replay improve sample efficiency at fixed interaction budget?
2. Does a world-model-assisted planner outperform tabular Q-learning on held-out mazes?
3. Which retention techniques prevent performance regression across task sequences?
4. Do self-generated tasks lead to generalization rather than benchmark memorization?
5. When do acquired procedures transfer from simulator tasks to bounded code tasks?
6. Can validated local hyperparameter improvements accumulate without overfitting candidate-selection benchmarks?

Each question requires an explicit control and a predeclared measurable outcome.
